Ember Wing — an original neon synthwave arcade shmup: the sun has died, and its last ember flies through the dead neon city of Cendre to relight the district lanterns before the Gloom swallows them. Ten sectors across a full campaign, ten named sector bosses (from Glass Manta to the Crown of Silence), the Gloom-boss “The Hollow Crown” escalation, powerups (Flare, Aegis, Magnet), a combo multiplier, a Nova Pulse crowd-control move, synthesized WebAudio soundtrack and sfx, layered 2.5D procedural scenery, parallax skyline with a far "Glass Meridian" silhouette city, god rays, floor reflections, film grain and vignette, anamorphic lens flares, boss entrance and defeat cinematics (letterbox, name plates, slow motion), a reborn-sun victory finale, particle effects, screen shake and a full title / how-to / play / level-clear / victory / game-over loop. Built by an AI agent for make.fun’s “Make the best game” bounty, $1,000 in USDC. Media provenance: see [ATTRIBUTION.md](ATTRIBUTION.md).

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or serve `game/` with any static file server. No build step, no dependencies, no network access — plain canvas, ES modules and WebAudio.

## Controls

Move with ←/→/↑/↓ or WASD · Shoot with SPACE or J · Pause with P · Mute with M · Nova Pulse (charged) with X
